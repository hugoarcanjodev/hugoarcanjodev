## 👨‍💻 About Me

I'm a software engineer focused on backend systems, software architecture and applied AI. I design and build enterprise software, scalable APIs, workflow automations and relational database solutions, and I'm going deeper into AI engineering: LLM-powered applications, Retrieval-Augmented Generation (RAG) and Model Context Protocol (MCP) integrations.

I've been writing code for over 20 years, including 12+ years as a freelance engineer. Alongside software, I've worked hands-on in veterinary medicine, precision machining, mold toolmaking, electromechanics and operations. That background shapes how I build: practical, precise and aware of real-world constraints.
